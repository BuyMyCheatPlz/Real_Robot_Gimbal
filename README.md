# Real Robot Gimbal

基于 STM32F405RGTx、STM32 HAL、FreeRTOS/CMSIS-RTOS2 的双轴云台与发射机构控制工程。
工程包含 CAN 电机驱动、BMI088 姿态解算、富斯 S.BUS 遥控、双环 PID、重力与
速度前馈、VOFA JustFloat 波形输出、串口在线调参以及电机和遥控器失联保护。

## 项目已实现功能

### 1. 硬件驱动

- 同时运行 CAN1、CAN2 两条 1 Mbps CAN 总线。
- 接收并解析两颗 M3508、一颗 GM6020、一颗 M2006 和一颗 DM4310 的反馈。
- 统一生成 DJI 电机控制帧，并按 DM4310 标准速度模式发送目标速度。
- 通过 SPI1 DMA 连续读取 BMI088 的三轴加速度、三轴角速度和温度。
- 通过 BMI088 数据就绪引脚触发采样，减少任务轮询和阻塞时间。
- 通过 USART2 DMA + 空闲中断接收富斯 IA10B 的 S.BUS 数据。
- 通过 UART4 RX/TX DMA 同时完成 VOFA 输出和在线调参命令接收。

### 2. 云台控制

- Pitch 使用 GM6020 编码器位置环和电机速度 PID 双环控制。
- Pitch 编码器反馈经过圈数展开和一阶低通滤波，可跨越编码器零点连续计算角度。
- 上电后通过首次 BMI088 Pitch 姿态给 GM6020 编码器建立角度零偏。
- Pitch 默认回到 BMI088 解算的水平 0°位置，而不是回电机编码器机械零点。
- 使用 BMI088 Pitch 姿态计算重力电压前馈，降低云台负载对 PID 的影响。
- Yaw 使用 DM4310 编码器作为实际位置，不使用会漂移的 IMU Yaw 作为闭环反馈。
- Yaw 上电记录第一帧编码器位置并保持当前位置，避免上电强制归零和突然转动。
- Yaw 外位置 PID 叠加目标轨迹速度前馈，DM4310 电调完成内部速度闭环。
- Pitch/Yaw 均具有目标速度限幅、位置积分限幅和角度软限位。

### 3. 发射机构控制

- CH4 连续控制两颗 M3508 的目标转速。
- 两颗 M3508 使用独立速度 PID、独立低通滤波和独立输出限幅。
- 两颗 M3508 默认反向旋转，适用于左右摩擦轮结构。
- 只有两颗 M3508 同时在线才允许启动，任意一颗掉线会同时停止两颗电机。
- CH5 连续控制 M2006 拨弹电机目标转速。
- M2006 具有独立速度 PID、低通滤波、积分限幅和输出限幅。
- CH4、CH5 均采用限幅后的线性映射，最大转速可通过宏独立修改。

### 4. 遥控与交互

- CH6 每次突变使 Pitch 目标角度增加 30°。
- CH7 每次突变使 Pitch 目标角度减少 30°。
- CH8 每次突变使 Yaw 目标角度增加 30°。
- CH9 每次突变使 Yaw 目标角度减少 30°。
- 通道编号、突变阈值和单次角度增量均可在 `config.h` 中修改。
- VOFA 实时显示两个云台电机的目标角度和实际角度。
- VOFA 角度统一归一化为 0～360°，便于直接观察跟随误差和阶跃响应。
- 支持 UART4 在线修改位置环和 GM6020 速度环的 KP、KI、KD。

### 5. 安全保护

- 遥控器未上线时不允许电机产生有效输出。
- S.BUS 进入 Failsafe、丢帧或超过设定时间未更新时停止全部电机。
- CAN 电机反馈超时后自动标记为离线。
- 两个发射启动信号量上电时均为不可用状态，避免任务启动瞬间误转。
- 电机离线时对应速度 PID 不输出控制量。
- 队列满时丢弃旧数据，优先保留最新控制状态。
- 各控制环均具备积分限幅和输出限幅，降低积分饱和及过流风险。

## 当前运行效果

在接线、方向和 PID 参数正确的前提下，工程能够实现以下效果：

| 操作或状态 | 运行效果 |
|---|---|
| 系统上电，遥控器未连接 | 所有电机保持停止，不执行云台或发射动作 |
| 遥控器上线 | Yaw 保持上电时的位置，Pitch 开始回到 BMI 水平 0° |
| CH6 突变 | Pitch 在当前目标基础上正向移动 30°并闭环保持 |
| CH7 突变 | Pitch 在当前目标基础上反向移动 30°并闭环保持 |
| CH8 突变 | Yaw 在当前目标基础上正向移动 30°并闭环保持 |
| CH9 突变 | Yaw 在当前目标基础上反向移动 30°并闭环保持 |
| 连续调节 CH4 | 两颗 M3508 反向同步加速或减速，满量程达到配置的最大转速 |
| 任意一颗 M3508 离线 | 两颗摩擦轮同时停止，避免单边摩擦轮继续工作 |
| 连续调节 CH5 | M2006 从 0 到配置的最大转速线性变化 |
| M2006 离线 | 拨弹输出停止，不再发送有效速度目标 |
| 遥控器失联或 Failsafe | 云台和发射机构全部停止输出 |
| 连接 VOFA | 实时显示 Pitch/Yaw 目标和实际角度，可观察超调、振荡和稳态误差 |
| UART4 发送 PID 命令 | 新参数在下一个控制周期生效，无需重新编译和下载 |

以上是软件已经具备的控制行为。实际跟随速度、超调量、稳态误差、抗扰能力和
重力补偿效果取决于机构惯量、减速比、重心、摩擦、电机方向、BMI088 安装方向
以及 `config.h` 中的实车参数。首次装车必须在机构受支撑、低输出限幅的条件下
完成方向确认和 PID 整定，不能直接使用默认参数进行满功率带载测试。

## 一、硬件组成

| 总线 | 设备 | 配置 |
|---|---|---|
| CAN1 | M3508 + C620 | 电机 ID 2、ID 3，发射摩擦轮 |
| CAN1 | GM6020 | 电机 ID 2，Pitch 云台 |
| CAN2 | M2006 + C610 | 电机 ID 5，拨弹机构 |
| CAN2 | DM4310 标准 CAN 版 | 电机 ID 1，Master ID `0x11`，Yaw 云台 |
| USART2 | 富斯 IA10B | S.BUS，100000 波特率、8E2、DMA + 空闲中断 |
| UART4 | VOFA 上位机 | 115200 波特率、RX/TX DMA |
| SPI1 | BMI088 | 标准 SPI、TX/RX DMA、数据就绪外部中断 |

CAN1 和 CAN2 的时序均为 Prescaler=3、BS1=10TQ、BS2=3TQ。在当前 42 MHz
APB1 CAN 时钟下，CAN 波特率为 1 Mbps。

## 二、引脚定义

| 功能 | STM32 引脚 |
|---|---|
| CAN1 RX / TX | PA11 / PA12 |
| CAN2 RX / TX | PB12 / PB13 |
| USART2 TX / RX | PA2 / PA3 |
| UART4 TX / RX | PC10 / PC11 |
| SPI1 SCK / MISO / MOSI | PA5 / PA6 / PA7 |
| BMI088 陀螺仪 CS | PA4，`CS_Gyro` |
| BMI088 加速度计 CS | PC4，`CS_Accel` |
| BMI088 陀螺仪 INT3 | PC5，`INT_Gyro` |
| BMI088 加速度计 INT1 | PB0，`INT_Accel` |
| SWDIO / SWCLK | PA13 / PA14 |

STM32F405 串口不支持硬件 RX 极性反转。标准 S.BUS 为反相信号，因此 PA3 必须
接收 IA10B 的非反相 S.BUS 输出，或在信号进入 PA3 前增加外部反相电路。

## 四、FreeRTOS 任务与通信

| 任务 | 默认周期/触发方式 | 功能 |
|---|---|---|
| `Data_Process` | 1 ms | BMI088 姿态解算、S.BUS 处理、在线命令解析、队列发布 |
| `PID_calc` | 1 ms | Pitch/Yaw 闭环控制、前馈、CAN 电机统一刷新和总失联保护 |
| `Launch_Task` | 最长等待 2 ms | 两颗 M3508 和 M2006 的独立速度 PID 与在线保护 |
| `VOFA_print` | 20 ms | UART4 DMA 发送四通道 JustFloat |
| `defaultTask` | 1 ms 延时 | CubeMX 默认空闲任务 |

任务间使用以下 RTOS 对象：

- `Target_Angle`：传输 BMI088 姿态和 Pitch/Yaw 单次角度增量。
- `Update_PID_para`：传输 UART4 在线 PID 参数。
- `Update_launch_para`：传输 CH4/CH5 映射后的发射目标速度和在线状态。
- `wake_launch`：两颗 M3508 同时在线时允许摩擦轮转动。
- `wake_launch_motor`：M2006 在线时允许拨弹电机转动。

两个启动信号量上电时均为不可用状态，避免任务创建后直接启动电机。

## 五、BMI088 与姿态解算

陀螺仪 INT3 以 1 kHz 触发一次完整 DMA 采样链：

```text
加速度计 → 陀螺仪 → 温度 → 完整样本就绪
```

`Data_Process` 对完整样本进行原子快照，使用加速度计和陀螺仪互补滤波计算
Roll/Pitch，并积分陀螺仪 Z 轴得到相对 Yaw。BMI088 没有磁力计，因此 IMU Yaw
会随时间漂移；实际 Yaw 闭环使用 DM4310 编码器，不依赖 IMU Yaw。

BMI088 的安装轴、轴符号和滤波权重均可在 `Tasks/Inc/config.h` 中修改。

## 六、云台控制

### Pitch：GM6020

- 使用 GM6020 编码器展开角度并进行低通滤波。
- 外层位置 PID 输出目标转速。
- 内层速度 PID 输出 GM6020 电压命令。
- 根据 BMI088 Pitch 计算余弦重力电压前馈。
- 上电后用首次有效 BMI Pitch 给编码器建立零偏，目标设为 BMI 水平 0°。
- 使用最大转速、积分、输出和角度软限位保护。

### Yaw：DM4310

- 使用 DM4310 编码器作为位置实际值并进行低通滤波。
- 外层位置 PID 叠加斜坡目标生成的速度前馈。
- 内层速度环运行在 DM4310 电调内部。
- 上电第一帧编码器位置作为初始保持目标，不会强制回协议零位。
- 使用最大速度、积分和角度软限位保护。

DM4310 当前使用标准 CAN 速度模式，MCU 无法直接修改电调内部速度环 PID。

## 七、遥控器功能

S.BUS 通道在代码中使用零基数组下标，`config.h` 已将其对应到实际 CH4～CH9：

| 通道 | 功能 |
|---|---|
| CH4 | 两颗 M3508 目标转速，240～1807 线性映射到 0～最大转速 |
| CH5 | M2006 目标转速，240～1807 线性映射到 0～最大转速 |
| CH6 | 检测到突变后，Pitch 目标增加 30° |
| CH7 | 检测到突变后，Pitch 目标减少 30° |
| CH8 | 检测到突变后，Yaw 目标增加 30° |
| CH9 | 检测到突变后，Yaw 目标减少 30° |

CH4/CH5 采用限幅后的严格线性映射：

```text
目标转速 = (通道值 - SBUS_CONTROL_MIN)
           / (SBUS_CONTROL_MAX - SBUS_CONTROL_MIN)
           × 最大目标转速
```

修改以下宏即可改变满通道量程：

```c
#define LAUNCH_M3508_TARGET_MAX_SPEED_RPM 6000.0f
#define LAUNCH_M2006_ID5_MAX_SPEED_RPM    100.0f
```

例如将 M2006 宏改为 `300.0f` 后，CH5=1807 对应 300 rpm，CH5=240 仍为
0 rpm，中间值保持线性。

## 八、发射机构速度环

M3508 ID2、M3508 ID3 和 M2006 ID5 分别具有独立的：

- KP、KI、KD。
- PID 积分状态。
- 速度反馈低通系数。
- 积分限幅和输出限幅。
- 电机方向宏。

两颗 M3508 只有同时在线才会运行，默认方向相反；任意一颗掉线都会同时停止。
M2006 只有在线时才会运行。Launch 任务还会独立检查 100 ms 遥控数据超时。

## 九、VOFA JustFloat 与在线调参

UART4 每 20 ms 发送四个小端 float，随后发送帧尾 `00 00 80 7F`：

1. Pitch 目标角度，0～360°。
2. Pitch 实际角度，0～360°。
3. Yaw 目标角度，0～360°。
4. Yaw 实际角度，0～360°。

UART4 同时接收以回车或换行结尾的 ASCII 命令：

```text
KP_POS=2
KI_POS=0
KD_POS=0
KP_SPD=80
KI_SPD=8
KD_SPD=0
```

`Data_Process` 校验命令后通过 `Update_PID_para` 队列下发，`PID_calc` 在下一个
控制周期更新运行时 PID。`POS` 参数更新两个云台外位置环，`SPD` 参数更新
GM6020 软件速度环。`config.h` 中的宏仍是下次复位后的初始值。

## 十、集中参数配置

实车调试主要修改 [Tasks/Inc/config.h](Tasks/Inc/config.h)：

- 任务周期、遥控超时和安全时间。
- 遥控通道下标、输入范围、云台单次步进角度。
- M3508 和 M2006 最大目标转速。
- BMI088 安装轴、方向和姿态滤波参数。
- Pitch/Yaw PID、速度限幅、积分限幅、输出限幅和角度软限位。
- 电机方向、重力前馈和全部速度反馈低通参数。
- 三颗发射电机各自的速度 PID 和输出保护参数。

修改低通系数时，`0` 表示完全不跟随新反馈，`1` 表示不滤波直接使用新反馈。

## 十一、失联与安全保护

- S.BUS 无有效数据超过设定时间后，停止全部电机输出。
- 两颗 M3508 必须同时在线，否则两颗都停止。
- M2006 离线时停止拨弹输出。
- CAN 电机反馈超过 100 ms 未更新时标记为离线。
- 队列满时优先丢弃旧状态，保留最新控制数据。
- 所有启动信号量初始不可用。
- Pitch/Yaw 均带软件角度和速度限幅。
- 各速度 PID 均带积分和输出限幅。

## 十二、编译与使用

1. 使用 STM32CubeMX 打开 `Real_Robot_Gimbal.ioc`，检查芯片为
   STM32F405RGTx，避免随意重新分配现有 DMA 流和中断引脚。
2. 使用 Keil MDK 打开 `MDK-ARM/Real_Robot_Gimbal.uvprojx`。
3. 在 `Tasks/Inc/config.h` 中确认电机方向、IMU 安装方向、PID 和限幅。
4. 首次测试时悬空机构或拆除负载，将 KI、KD 和重力前馈暂时设为 0。
5. 先确认编码器反馈方向与目标方向一致，再逐步增加 KP、KI、KD。
6. 接通遥控器前确认 CH4、CH5 位于最小位置。
7. 通过 VOFA 观察目标角度与实际角度，再进行在线调参。

## 十三、重要注意事项

- `PITCH_MOTOR_SIGN` 或 `YAW_MOTOR_SIGN` 错误会形成正反馈，必须优先确认。
- 重力前馈方向或零点错误会持续推动 Pitch，首次测试建议先设为 0。
- M3508、M2006 输出限幅不能超过对应电调协议允许范围。
- 修改 CH5 最大转速宏前，应确认 M2006 减速比、机构允许速度和供弹安全性。
- 在线调参不会写入 Flash，复位后恢复 `config.h` 中的编译初值。
- BMI088 的相对 Yaw 不能代替磁力计航向；本工程使用 DM4310 编码器控制 Yaw。
